# 换歌 / 换主题说明（MV 模式 + 卡拉OK 歌词）

## 1. 准备素材（放进一个文件夹，例如 `D:\FPGA\contest\theme`）
| 文件 | 说明 |
|---|---|
| `song.mid`（或 `.kar`） | 歌曲 MIDI，要有清楚的主旋律轨 |
| `lyrics.txt` | 歌词，UTF-8。没有这个文件时自动用 .kar 自带的逐字歌词 |
| 4 张图片 | 转成 640x480 BMP 后拷到 TF 卡（文件名按顺序：图 1~4） |

`lyrics.txt` 写法：
```
TITLE 歌名 - 原唱              ← 可选，前奏时显示（浅蓝色）
@12.35 第一句歌词              ← @秒数 = 这句在 MIDI 里的开始时间
@15.80 [2] 第二句              ← [2] = 从这句开始切到第 2 张图
@20.10 [3:圆形] 第三句         ← 指定转场样式：淡入 / 擦除 / 百叶 / 圆形
爱__                           ← 一个字唱多个音：每多一个音加一个 _
# 注释行
```
也可以直接用 LRC（`[00:12.35]歌词`），时间和 MIDI 对不上时改脚本里的 `OFFSET_SEC`。

## 2. 运行脚本
1. 打开 `src/user_source/hdl_source/my/theme/gen_theme.py`，改顶部“用户配置区”：
   - `THEME_DIR`：素材文件夹
   - `START_SEC` / `END_SEC`：截取片段（建议 60~120 秒）
   - `MELODY_TRACK`：一般不用改（自动挑主旋律）；挑错了就按打印出来的列表填 `(轨道号, 通道号)`
2. 运行：`D:\Python313\python.exe gen_theme.py`
3. 检查输出（都在 `my/theme/`）：
   - `preview.wav`：电脑上先听旋律对不对
   - `preview_timeline.txt`：每句歌词的时间、切图时间；有 `[注意]` 的地方要检查字数或加 `_`
   - `glyph_preview.png`：字库预览
4. TD 重新编译（`build.bat`），烧录。

## 3. 限制
- 不同的字 ≤ 256 个，总字数 ≤ 1024，句数 ≤ 255，音符+休止 ≤ 1024 个（超了脚本会报错，截短片段即可）
- 一句最多 22 个字（更长会自动拆成两行）
- 相邻两次切图最好间隔 3 秒以上（每次转场约 1 秒）

## 4. 板上操作
- **KEY4**：模式循环 手动 → 定时轮播 → **MV**（进入 MV 时音乐从头开始，图片跟着歌词段落自动转场）
- **SW3**：歌词 + 波形显示开关；**SW2**：转场特效开关；**SW1**：声音
- 数码管第 2 位：`-` 手动，`A` 轮播，`P` MV
