# 模板使用说明：几行代码加一个新功能

所有代码在 `src/user_source/hdl_source/my/`。整个系统按"像素流"组织：
每一级模块输入一根 `vi`、输出一根 `vo`（47 位总线，定义在 `common/vid_defs.vh`），
里面打包了 `vs hs de x y rgb`。新功能 = 在效果链里插一级。

## 一、加一个画面效果（例：灰度）

1. 复制 `fx/fx_template.v` → `fx/fx_gray.v`，把 `module fx_template` 改成 `module fx_gray`
2. 只改"用户代码区"那一行：
   ```verilog
   wire [15:0] sum     = r * 8'd77 + g * 8'd150 + b * 8'd29;   // 先用 16 位接住，避免截断
   wire [7:0]  gray    = sum[15:8];
   wire [23:0] rgb_new = {gray, gray, gray};
   ```
   注意：Verilog 运算的位宽由等号左边决定，乘加结果要先放进足够宽的线再取高位。
   可直接用的变量：`x y`（坐标）`r g b`（分量）`rgb` `de` `frame_start`（每帧一拍，做动画计数）
3. 在 `my_top.v` 效果链里接一行（把上一级的 vo 接到 vi，原来的下一级改接新输出）：
   ```verilog
   wire [`VB-1:0] v_gray;
   fx_gray u_gray(.clk(video_clk), .rst(rst), .en(sw_xxx), .vi(v_osd), .vo(v_gray));
   ```
4. 在 TD 工程里加这个文件（或在 `src/td_my/add.tcl` 里加一行 `add_files`），编译烧录。

常用写法：
| 效果 | 用户代码区 |
|---|---|
| 反色 | `rgb_new = ~rgb;` |
| 只留红色 | `rgb_new = {r, 8'd0, 8'd0};` |
| 画一个框 | `rgb_new = (x==100 \|\| x==300 \|\| y==100 \|\| y==200) ? 24'hFF0000 : rgb;` |
| 左半屏变暗 | `rgb_new = (x < 320) ? {1'b0,r[7:1],1'b0,g[7:1],1'b0,b[7:1]} : rgb;` |

需要外部参数（如强度）：在端口里加 `input wire [7:0] level`，顶层接 `param_ctrl` 的寄存器。

## 二、改 OSD 显示的文字

编辑 `osd/gen_osd.py` 顶部三处，然后运行 `python gen_osd.py`（自动生成 `osd_writer.v`）：
- `STATUS`：状态栏文字，`{名字}` 是动态字段
- `SUBTITLE`：底部滚动字幕
- `FIELDS`：每个动态字段的 Verilog 表达式（每个表达式 = 一个字符）

## 三、加一个可调参数

在 `ctrl/param_ctrl.v`：加一个寄存器，在 `inc` / `dec` 的 case 里各加一行；把 `item` 位宽加大。
再在 `gen_osd.py` 的 STATUS / FIELDS / MENU 里加上它，就能在 OSD 上显示和选中。

## 四、换音乐

编辑 `audio/gen_songs.py` 里的 `SONGS`（音名 + 时值），运行 `python gen_songs.py`。
第 k 首曲子对应第 k 张图片。

## 五、先仿真再上板（推荐）

`sim/tb_fx_image.v` 会把两张真实图片送进效果链，输出 `out.png`：
```
python sim/img_tool.py tohex 图片1 sim/run_fx/a.hex
python sim/img_tool.py tohex 图片2 sim/run_fx/b.hex
（ModelSim 编译 tb_fx_image.v 和效果模块，运行）
python sim/img_tool.py topng sim/run_fx/out.hex out.png
```
在电脑上看 out.png 确认效果正确，再编译烧录，能省很多上板调试时间。
