# EG4S20 HDMI 多媒体播放系统 使用说明（v9）

## 一、硬件准备
| 项目 | 说明 |
|---|---|
| 开发板 | HX4S20C（EG4S20BG256），板载 Flash 已固化程序，上电即运行 |
| 显示器 | HDMI 线接板子的 **HDMI_B** 口，显示器输入 640×480@60Hz（带声音） |
| TF 卡 | FAT32 格式，插在板子**背面**卡槽；根目录放 4 张 BMP（见第六节） |
| 电源 | 板子供电；每次换卡或卡出问题时，**整板断电再上电** |

## 二、上电过程
1. 上电后先显示**彩条**，底部色带表示状态：**黄 = 正在读卡装载**，蓝 = 卡未就绪，红 = 文件系统错误。
2. 约 2~3 秒后 4 张图装载完成，显示第 1 张图（所有图片一次性预载进 SDRAM，之后切图不再读卡）。
3. 停在蓝色/红色色带：检查卡是否插紧、格式是否 FAT32，然后整板断电重启。

## 三、拨码开关（拨上 = 开）
| 开关 | 功能 |
|---|---|
| SW1 | 声音开关 |
| SW2 | 转场特效开关（关 = 直接切换） |
| SW3 | 信息层：卡拉OK 歌词 + 演唱小人（茂茂）+ 音频波形/音量柱（波形需 SW1 开） |
| SW4 | 设置模式（屏幕顶部出现参数菜单） |
| SW6 | 数码管显示（下 = 双色灯） |

## 四、按键（板子下沿，从右往左：Config、KEY1、KEY2、KEY3、KEY4）
| 按键 | 普通模式（SW4 下） | 设置模式（SW4 上） |
|---|---|---|
| KEY1 | 复位（重新装载图片、音乐从头） | 同左 |
| KEY2 | 下一张 | 当前参数 **加** |
| KEY3 | 切换轮播周期 2 / 3 / 5 / 8 秒 | **选择**参数项（亮度 → 对比度 → 音量 → 周期） |
| KEY4 | 切换模式：**手动 → 定时轮播 → MV** → 手动 | 当前参数 **减** |

- 设置项范围：亮度 -8~+7，对比度 0~15（默认 8），音量 0~15（默认 6），周期 2/3/5/8 秒。
- 任意按键后屏幕顶部状态栏显示约 3 秒：`IMG 当前/总数  MODE 模式  PERIOD 周期  BRIGHT 亮度  CONTRAST 对比度  VOLUME 音量  FADE 转场`。

## 五、三种播放模式
| 模式 | 数码管第 2 位 | 行为 |
|---|---|---|
| 手动 | `-` | KEY2 切图；转场轮换 淡入淡出 / 擦除 / 百叶窗 / 圆形展开 |
| 定时轮播 | `A` | 按设定周期自动切图（KEY3 改周期） |
| MV | `P` | 进入时音乐从头播放；图片在乐句处自动转场（亮度溶解 / 经白 / 经黑，约 1.4 秒），歌词卡拉OK 逐字变色，右下角茂茂跟着旋律张嘴、点头 |

- MV 内容：《此生不换》两段主歌 + 副歌（约 98 秒），唱完停 1 秒循环。
- 歌词颜色：未唱 = 亮青，正在唱/已唱 = 橙黄渐变，歌名 = 粉色；KTV 式上下两行交替，另一行预告下一句。
- 音乐在任何模式下都持续播放；MV 模式下 KEY2 仍可手动切图。

## 六、数码管（SW6 拨上，从左到右）
| 位 | 含义 |
|---|---|
| 1 | 轮播周期（秒） |
| 2 | 模式：`-` 手动 / `A` 轮播 / `P` MV |
| 3 | 当前图片序号 |
| 4 | 图片总数 |
| 5、6 | 装载中：SD 卡状态 / 装载状态（8 = 卡就绪，5 = 装载完成）；装载完成后：SDRAM 刷新计数（十六进制，正常约 `54`） |

## 七、TF 卡图片准备
- BMP 24 位、640×480；最多 4 张，**按播放顺序逐个拷贝**（板子按写入卡的先后顺序读取，不要一次全选拖入）。
- 本作品的 4 张图在 `D:\FPGA\contest\tf_theme\`（1 时光 / 2 师徒 / 3 长安 / 4 紫萱）。
- 换图、换歌：见 `换歌说明.md`（脚本由 MIDI + 歌词自动生成乐谱、字幕、字库）。

## 八、常见问题
| 现象 | 处理 |
|---|---|
| 一直彩条 + 蓝色色带 | 卡未初始化：整板断电重启（JTAG 重烧后尤其需要） |
| 红色色带 | 卡不是 FAT32 或没有 BMP |
| 没声音 | SW1 拨上；设置模式检查音量；确认显示器/电视有喇叭且未静音 |
| 图片顺序不对 | 清空卡后按顺序逐个拷贝 |
| 没有歌词/小人 | SW3 拨上；需图片装载完成后才显示 |

## 附：演示视频拍摄建议（约 4~5 分钟）
1. **开场（20s）**：画面同时拍到板子和显示器，SW6 拨上。上电 → 彩条 + 黄色装载带 → 约 2 秒出图（体现启动速度、全部预载）。
2. **基础功能（60s）**：
   - SW2 关，按 KEY2 直接切图；SW2 开，连按 KEY2 展示 4 种转场（淡入淡出、擦除、百叶窗、圆形）。
   - 拨 SW1 开关声音，展示 HDMI 音频；KEY4 切到定时轮播（数码管 `A`），KEY3 改周期，状态栏显示周期变化。
3. **设置菜单 + OSD（50s）**：SW4 拨上，KEY3 选“亮度”，KEY2/KEY4 调亮调暗；再调对比度、音量，屏幕顶部 `>` 指示当前项。SW4 拨回。
4. **音频可视化（20s）**：SW3 拨上，镜头给到左下波形和音量柱随音乐跳动。
5. **MV 模式（100s，重点）**：KEY4 切到 `P`，完整播放一遍：前奏粉色歌名 → 歌词逐字变色 → 4 次电影感转场 → 右下角茂茂张嘴点头 → 结尾经黑淡化循环。
6. **结尾（20s）**：断电再上电，演示程序固化在 Flash、上电即用；简单说明架构（纯 FPGA，无处理器）。

拍摄小技巧：
- 有 HDMI 采集卡的话，直接录 HDMI 信号做主画面，手机拍板子做小窗，画面最清楚、没有摩尔纹，声音也最干净。
- 用手机直拍屏幕时：屏幕亮度调低一点、镜头稍微斜一点，可以减轻摩尔纹；音量设 4~6 档避免破音。
- 拍摄前按 KEY1 复位一次，保证 MV 从头开始。
